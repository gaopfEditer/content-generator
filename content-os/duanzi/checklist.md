# 段子机械自检清单

交本人品鉴前须全部勾选为「是」。任一项「否」→ 回结构设计，不改措辞凑数。

- [ ] 正文汉字数 ≥ 180 且 ≤ 450（极端可 150～500；**< 120 硬失败**）
- [ ] 结构槽位六项已填：场景 / 铺垫期待 / 拐点 / 反转 / 余味 / 长度目标
- [ ] 场景含具体名词 ≥ 3（非「有个人」「某天」）
- [ ] 反转与铺垫同一因果链，不是硬拐题
- [ ] 反转后仍有 ≥ 1 句余味，且非「绝了/无语/你觉得呢」
- [ ] 未用交易话术冒充资讯（偏多偏空、验证失效、目标价等）
- [ ] 未踩禁区（人身攻击、未成年、仇恨、未核实指控）
- [ ] 已标 `author: 段子创作`（或本产线 Agent 名）
- [ ] 文件落在 `content-os/duanzi/`，未写入资讯 `topics/` 冒充日报

**说明**：笑点聪不聪明、尺度、值不值得发 → 仅本人品鉴，本清单不判。
