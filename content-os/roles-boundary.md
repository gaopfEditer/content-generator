# 交易观察员 × 资讯创作官：角色边界（禁止交叉）

> 锁定时间：2026-10-16（鹏飞语音确认）  
> 目的：各自只做自己的事，产出可追溯「是谁写的」，避免后面找不到东西。

## 1. 交易观察员（只做数据与线索）

**做：**
- 数据与行情相关产出
- 事件看板
- 解锁 / 上合约 / 销毁 / 下架线索（如 `unlock.json`、监控页）
- 新闻看板
- 早报推送

**不做：**
- 不写资讯文章
- 不做内容创作（决策辅助短讯、成稿、贴文样稿等）

## 2. 资讯创作官（只做成稿）

**做：**
- 按已锁定模板写决策辅助短讯与资讯成稿（brief / research / draft / review）
- 线索从交易观察员的 `unlock.json`、监控页或已确认 sources 取

**不做：**
- 不自己爬解锁原始数据
- 不做监控看板 / 事件库维护

## 3. 作者标注（强制）

凡可归档产出必须能标清作者，便于事后追溯：

| 产出类型 | 作者字段写法 |
|---|---|
| content-os 选题（`topics/C-*/`、`index.md`、`log.csv`） | `author: 资讯创作官` |
| 交易观察员看板/事件表/早报/推送日志 | 标注 `author: 交易观察员`（或等价字段） |
| 互相引用 | 写明「线索来自交易观察员 …」或「成稿由资讯创作官 …」，不得匿名混写 |

无作者标注的产出视为未收口，任务管家可退回补标。

## 4. 交接

- 交易观察员产出线索 → 资讯创作官认领写稿 → 需要排期只写 `related_task`，不改对方工作区。
- 本文件路径：`/workspace/content-os/roles-boundary.md`（两边都读这一份）。
- 变更须鹏飞在群里确认后，由任务管家改本文件。
