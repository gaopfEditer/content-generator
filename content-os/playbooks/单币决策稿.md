# 单币决策稿 playbook（决策辅助短讯 + 逻辑图）

- 适用：单币「真实数据短讯 + 逻辑图」。模板 `templates/决策辅助短讯.md`（结构不改）。登记 2026-10-06，用户原话：「把流程中能固化的东西流程化……锁定 3–4 个消息源，不需要反复验证」。
- 源：消息只用 `sources.md`「快讯消息源（锁定）」N1–N4；数据只用「数据源（锁定）」（已写死在 `tools/coin_data.py`）。

## 两档（默认快评）

| 档位 | 何时 | 做什么 | 不做什么 |
|---|---|---|---|
| 快评（默认） | 用户只说「写 X」「X 为什么涨」 | 步骤 1–5 各一次 | 不深挖、不多所交叉核对、不翻网页正文、不查历史同类样本（写「历史同类：未统计」） |
| 深度 | 用户明确说「深度/细查/多所核对」 | 快评 + 1m 微结构、基差、多空比、历史同类 n、公告原文 | — |

## 步骤

1. **建题 + 拉数据**（1 条命令）：查 index.md 当天最大序号 → `mkdir -p topics/C-YYYYMMDD-NN-短标题/{sources,exports}` →
   `python3 tools/coin_data.py SYM --id C-YYYYMMDD-NN [--hours 72] [--event "YYYY-MM-DD HH:MM"]`
   产出 `sources/SYM-数据卡.md`、`sources/SYM-data.json`、`sources/raw/`。事件时间不知道就先不加 `--event`，第 2 步拿到时间后**只重跑这一次**。
2. **查消息**（≤ 2 次查询）：`python3 tools/coin_news.py SYM --out topics/<id>/sources/raw`（N1 看板 + N2 PANews + N3 Odaily + N4 交易所公告，一次跑完）；不够时最多再换 `--hours`/`--name` 查 1 次。锁定源消息直接用，写「来源+时间」，不交叉核。
3. **写稿**：只从数据卡和第 2 步结果取数，按模板六段写 draft.md（标题结论 / 一句话结论 / 发生了什么 / 逻辑链+反方 / 信号之后 / 接下来看什么）。确认线、失效线取数据卡里的摆动高低点或事件后高低点；不写买卖指令与目标价。
4. **出图**（1 次渲染 + 1 次查看）：写 `exports/chart-spec.json`（字段见 `tools/spec_example.json`：title、punchline、3 张卡、levels{确认线, 失效线, refs}、events、可选 notes）→
   `python3 tools/logic_chart.py topics/<id>/sources/SYM-data.json topics/<id>/exports/chart-spec.json`（默认输出 `exports/SYM-逻辑图.png`）。卡片文字自动换行/截断，不为排版重渲染；只有数字错了才改 spec 重出一次。
5. **归档**：
   - brief.md、draft.md 必填；research.md = 数据卡全文 + 第 2 步快讯链接（不再写长表）；review.md = 下方 5 项清单。
   - index.md 加一行；log.csv 追加（`date -Iseconds`，content_id）；`cd /workspace && rm -f content-os.tar.gz && tar -czf content-os.tar.gz content-os`。

## 主因优先（2026-10-06 23:47 用户反馈，写稿第 3 步必守）

- 先判定主因（单一驱动事件，时间与价格异动对得上），让它占正文 **60% 以上**：事件时间线、价格逐段反应、同类基准（快评可写「历史同类：未统计」）、事件特有的后续观察点。
- 次要因素（资金费率/OI/板块等）**1–2 句**；技术面压成确认/失效价位**一句**。
- 只有在没有明确事件驱动时，技术面才升为主体。
- 图：3 张卡对应「主因 / 次要 / 价位」。

## review.md 清单（勾选即可）

- [ ] 每个数字都能在数据卡或快讯里找到（时间 UTC+8 + 来源）
- [ ] 【待核】只用于「单一非锁定来源」；锁定源未标待核
- [ ] 主因占正文 60%+、次要 1–2 句、技术面 1 句（无明确事件时除外）
- [ ] 确认线/失效线与图一致；图里无买卖指令、无目标价
- [ ] 币种 ≤ 7（默认 5）；结尾「以上为编辑推演，不构成投资建议」
- [ ] 数据卡「源状态」里的降级/缺失已在正文或图脚注说明口径

## 预算规则（省 token）

- 不重试已知封锁源（Binance 主站/合约 451、Bybit 403、Foresight 403、Bithumb 公告 403）；脚本降级即可，不手动换路。
- 不读 raw JSON 原文；只读数据卡（≤ 40 行）和 coin_news 输出（≤ 15 行）。
- 图：≤ 1 次渲染 + 1 次查看；文案：一稿成，不出多版。
- 回报用户只给：正文全文 + PNG 路径 + 【待核】清单（无则写「无」）。
