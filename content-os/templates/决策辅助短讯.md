# 决策辅助短讯模板

- 适用形式：短讯（单事件决策辅助 / 价值型信息流贴文）
- 适用渠道：渠道中立（可再适配 币安广场 / X / 公众号）；本模板先写中立正文
- 字数：常规帖正文汉字约 350–550（U+4E00–U+9FFF）；含表/多阶段技术分析可达约 600–800
- 视角：交易所运营信息流。用户不关心第一层事实本身（「X 解锁了」），而关心该币预期方向、逻辑、以及同类信号之后价格怎么走。事件事实只作引子。
- 背景：
  - 2026-10-05 用户反馈：纯客观事实不够，须含事件前后走势与伴生信号。
  - 2026-10-05 23:47 用户指令升级：成稿以「方向预期 + 逻辑链 + 信号后走势/历史同类 + 验证/失效信号」为主体；允许方向倾向与关键观察位；禁止买入/卖出/开多/开空指令与目标价。
- 用法：复制到 topics/C-YYYYMMDD-NN-短标题/draft.md 的「正文」里，按下列段落填写；段落顺序不改
- 示范：C-20261005-05（旧五段）；C-20261005-06（本结构 ×5 测试帖）

---

## 固定顶行与结尾

- 若为测试/虚构数据：正文第一行必须是「【测试数据】」；结尾固定：「【测试数据，非真实行情】以上为编辑推演，不构成投资建议」
- 若为真实已核数据：可改顶行为栏目标（如【决策辅助｜标的】）；结尾用「以上为编辑推演，不构成投资建议」

---

## 1. 标题

- 直接给结论：方向 + 核心理由（一句读完知道多空与为什么）。
- 不要纯事实标题（避免「XX 解锁」「XX 上线」单独成题）。

```text
标题：……偏多/偏空/中性——……
```

## 2. 一句话结论

- 格式：偏多 / 偏空 / 中性 + 强度（弱 / 中 / 强）+ 时间窗。

```text
一句话结论：偏空｜强度中｜时间窗 ……
```

## 3. 发生了什么（引子，1–2 句）

- 只作钩子：事件规模 / 时间戳（UTC+8）/ 关键口径。
- 不在本段展开涨跌归因；真实稿每个关键数字带来源或【待核】。

```text
发生了什么
……（时间戳）……
```

## 4. 逻辑链 + 反方

- 3–4 步：事件 → 供需机制 → 谁会买/卖 → 价格影响。
- 必须写一条反方理由（何种条件下方向失效或减弱）。

```text
逻辑链
1）……
2）……
3）……
4）……
反方：……
```

## 5. 信号之后发生了什么

- 本次：事件前后价格（带时间戳），尽量对照 BTC（或其它基准），可写相对 pp。
- 历史同类：样本量 n、上涨概率、中位涨跌（窗口写清，如 24h/72h）。
- 测试稿标明虚构样本；正式稿须可复核。

```text
信号之后发生了什么
本次：……（时1）价1 → ……（时2）价2（涨跌 …%）；同期 BTC：……；相对 BTC：…pp。
历史同类（n=…，口径…）：…h 上涨概率 …%，中位涨跌 …%。
```

## 6. 接下来看什么

- 2–3 个验证信号 + 1–2 个失效信号。
- 可用：资金费率、OI、交易所充净、关键价位站上/跌破、深度/价差、链上充提等。
- 写「观察什么」，不写「买入/卖出/开多/开空」；可写关键观察位，不写目标价。

```text
接下来看什么
验证：① ……；② ……；③ ……。
失效：① ……；② ……。
```

## 7. 结尾免责

```text
【测试数据，非真实行情】以上为编辑推演，不构成投资建议
```
（真实稿可去掉「测试数据」前缀，保留「以上为编辑推演，不构成投资建议」。）

## 主因优先规则（2026-10-06 23:47 用户反馈后新增）

- 动笔前先判定**主因**：有没有单一驱动事件（上所/下架、解锁、回购、黑客、监管、宏观数据等，且时间与价格异动对得上）。
- 有明确主因时：
  - 主因（事件时间线 + 价格逐段反应 + 同类基准/历史样本 + 事件特有的后续观察点）占正文 **60% 以上**；
  - 次要因素（资金费率、OI、板块等）压成 **1–2 句**；
  - 技术面压成**一句**「确认 X / 失效 Y（可附突破位）」；
  - 「接下来看什么」先列事件特有信号，再列价位。
- 只有在**没有明确事件驱动**时，技术面才升为正文主体（结构、量价、逻辑链 3–4 步）。
- 示范：C-20261006-02（BR，Bithumb 上韩元盘为主因）。

## 配图与点睛

- 每篇配 1 张逻辑图（点出关键节点与验证/失效线）+ 1 句点睛句。
- 点睛句置于标题正下方；图内可复用同一句作底部横幅。
- 图须含验证线与失效线（或等价观察位），避免买卖指令用语。

---

## 禁止项

- 禁止：买入 / 卖出 / 开多 / 开空 / 加仓 / 减仓 / 仓位比例 / 目标价 / 「应该」。
- 允许：偏多偏空与强度、时间窗、关键观察价位（站上/跌破作为验证或失效条件）。
- 数字必须内部自洽（涨跌幅、占比、表格 OHLC 与叙述一致）。

## 适用事件类型（示例）

- 代币解锁、永续/现货上架、下架、回购销毁、宏观数据后短周期结构（如威科夫 15m）等。

> 2026-10-16 临时标准（鹏飞群拍）：对外稿正文可暂不写「【待核】无。」与「以上为编辑推演，不构成投资建议。」结尾；读者默认「看盘做短线」；钩子用白话结论+观察条件，少用 EMA/相对 pp；无历史样本则整段删除不占位。
