# 解锁异动短讯模板

- 适用形式：短讯（运营 / 决策辅助）
- 适用渠道：渠道中立（可再适配币安广场 / X）
- 示范：`topics/C-20261016-02-STRK解锁前后行情/`（2026-10-16）
- 登记：2026-10-16（用户确认：针对 crypto-news 解锁看板异动事件）

## 适用范围（写死）

- **只写** [crypto-news 解锁看板](https://gaopfediter.github.io/crypto-news/events.html?type=unlock) 上的解锁事件。
- 触发条件：事件前后出现**较大异动**（提前约 7 天明显大涨，或解锁日/次日明显大跌/大涨）。小波动、走势平淡的解锁**不套本模板**。
- 线索来源：交易观察员 `unlock.json` / 监控页（资讯创作官不自爬解锁原始库）。
- 读者默认：看盘做短线的人。
- 无同名近似时才开新类讨论；本文件即「解锁异动」锁模板。

## 固定结构（顺序不改）

### 1. 白话结论（开头一句）
- 直接告诉读者：别追什么 / 别当什么 / 先看哪条线。
- 禁止纯事实标题（避免只写「XX 解锁」）。

### 2. 一句话结论 + 读者
```text
一句话结论：偏多/偏空/中性｜强度弱/中/强｜时间窗 ……
写给谁：看盘做短线的人。
```

### 3. 发生了什么（引子）
必填字段：
- 解锁时间（UTC+8）
- 解锁数量 / 估值（USD）/ 占流通占比
- 主要接收方（若有）
- 口径冲突时点明用哪家（CMC / DefiLlama 等）
- 盘面一段话：提前约 7 天高低点 → 解锁时价 → 解锁后/次日高低点（带时间戳）

### 4. 逻辑链（拆段，禁止混成一种逻辑）
至少分清：
1）**提前涨/跌**：主因通常是事件前抢跑/透支，还是另有叙事（须时间对得上）  
2）**解锁整点**：砸没砸、有没有被别的快讯接住  
3）**解锁后大涨/大跌**：卖消息、迟到抛压、新叙事、还是大盘拖累  
4）反方：何种价位/条件下方向降级或失效

### 5. 信号之后发生了什么
- 用「透支段 / 解锁段 / 之后段」时间线列价，不写「历史同类：未统计」占位（无样本就整段删历史）。

### 6. 接下来看什么（译成观察条件）
- 2 条价位观察：站上 X / 跌破 Y 分别意味着什么（不写买卖指令与目标价）。
- 可加：接收方是否继续出货、解锁占比是否还需第二段兑现。

### 7. 来源行
- 写明：交易观察员 unlock 线索；锁定快讯；数据卡时间。
- 文末是否加免责声明：按当时对外标准（2026-10-16 起暂可不写固定尾句）。

## 禁止
- 买入/卖出/开多开空/目标价/仓位。
- 把「提前七天涨」和「解锁后涨」写成同一种逻辑而不拆段。
- 无看板线索、无异动却硬套本模板。
